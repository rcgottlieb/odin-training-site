# Odin Training Site

This is a small training site for practicing HTML, CSS, JavaScript, Git, GitHub, and GitHub Pages.

The example site is about Casper, my rescue cat.

## Live site

GitHub Pages URL: [https://rcgottlieb.github.io/odin-training-site/](https://rcgottlieb.github.io/odin-training-site/)

## Training notes

This repo is intentionally simple.

The goal is to practice small, understandable commits.

This week expands the site with semantic HTML, including page sections, lists,
links, and an image placeholder.

GitHub Pages can be used to preview the site in a browser.

Future weeks will add CSS, layout, and JavaScript.
